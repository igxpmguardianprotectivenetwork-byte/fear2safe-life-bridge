# Fear2Safe — Life Bridge

Standalone UI matching the Fear2Safe Life Bridge design mockup (8 screens).

## Run

```bash
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).

## Screens

| Path | Screen |
|------|--------|
| `/` | Login (intro) → continues to `/home` |
| `/home` | Landing |
| `/dashboard` | User Dashboard |
| `/alerts/risk-detected` | Alert Details |
| `/guardians` | Guardians |
| `/device` | My Device |
| `/map` | Live Protection Map |
| `/reports` | Reports & Insights |
| `/settings` | Profile & Settings |

Demo login: use **Fill demo credentials**, or any email + password.

`pulse-hub` is not modified by this project.
